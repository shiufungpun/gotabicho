# Gotabicho Feature Map for Designers

This document maps the technical features to designer-friendly concepts.

| Feature Name           | Technical Description                         | Designer Concept       |
|:-----------------------|:----------------------------------------------|:-----------------------|
| **Trip List**          | `FlatList` or `Carousel` of Trip objects      | "The Journey Timeline" |
| **Receipt Extraction** | OCR & LLM parsing of images                   | "The Magic Accountant" |
| **Social Bookmark**    | URL metadata extraction from IG/Threads       | "Inspiration Inbox"    |
| **Settlement**         | Debt calculation between participants         | "Fair Share Ledger"    |
| **Map View**           | Geo-located attractions from bookmarks        | "The Spot Map"         |
| **Theme Provider**     | Dynamic `Colors` object with dark/light modes | "Ambiance Control"     |
