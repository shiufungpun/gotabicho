# Gotabicho Design AI Prompts

Use these prompts with AI design tools to generate assets and UI mockups.

## 1. Logo & Icon Redesign (DALL-E 3 / Midjourney)

> **Prompt:** "A minimalist app icon for a modern travel journal app named 'Gotabicho'. The icon should feature a
> continuous elegant line forming an abstract 'G' that resembles a stylized notebook or a winding travel path. Minimalist
> vector style, flat design, modern travel aesthetic. Use a primary color of Deep Indigo (#1565c0) or Sage Green. White
> background, high-end tech startup feel."

## 2. UI Dashboard (v0.dev / Claude / Galileo AI)

> **Prompt:** "Redesign a React Native mobile dashboard for a travel app called Gotabicho. Themes: Modern Travel,
> Glassmorphism. Features: A large 'Active Trip' card with a background image of a destination, a progress bar showing
> budget spent, and a grid of quick-action buttons (Add Receipt, Save Spot, AI Chat). Use large typography, soft shadows,
> and rounded corners (24px). The vibe should be airy, clean, and premium."

## 3. Social Bookmark Preview (v0.dev)

> **Prompt:** "Create a UI for a 'Social Bookmark Preview' screen. When a user shares an Instagram post to the app, show
> a large glassmorphic card with the post's thumbnail, a 'Source' badge (Instagram logo), and a multi-select list of trips
> to link the bookmark to. Include a 'Magic Extract' button that suggests categories like 'Cafe', 'Restaurant', or '
> Sightseeing' using AI."

## 4. Brand Color Palette

- **Primary:** `#1565C0` (Deep Blue) -> Update to `#2563EB` (Modern Blue)
- **Surface:** `#FFFFFF` (Solid) -> Update to `rgba(255, 255, 255, 0.8)` (Blurred)
- **Accent:** `#4CAF50` (Success) -> Update to `#10B981` (Emerald)
- **Background:** `#FBF7F2` (Parchment) -> Update to `#F8FAFC` (Slate White)
